# Privacy Policy

Last updated: August 23, 2026

Goal to Proof is an open-source instruction skill for AI coding agents. This policy covers the skill and the project website at `aiopshwang.github.io/goal-to-proof`.

## Data collection

Goal to Proof does not operate a backend, create user accounts, include analytics, set cookies, or collect telemetry. The plugin declares no MCP servers, apps, hooks, or background network services.

When you use the skill, your AI agent and host application may read files, run tools, or process prompts according to the permissions and privacy terms you configure with those providers. Goal to Proof does not receive that data.

## Public project services

GitHub hosts the source repository, issue tracker, discussions, releases, and project website. Information you submit to those services is handled by GitHub under its own policies and may be public. Do not post secrets or sensitive personal information in a public issue or discussion.

## Changes

Material changes will be documented in the repository and reflected by the date above.

## Contact

For privacy questions, open a GitHub issue without sensitive details. For a sensitive security or privacy report, use the repository's private security advisory channel.
