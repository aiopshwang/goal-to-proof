Privacy

Private work stays out of the skill.

Goal to Proof is an open-source instruction package. It does not include maintainer-operated telemetry, prompt collection, accounts, or a hosted agent service.

Effective date: August 23, 2026

What this policy covers

This page describes the Goal to Proof source repository, the distributed skill and plugin files, and the static documentation site at aiopshwang.github.io/goal-to-proof. It does not replace the privacy terms of GitHub, your AI host, your package installer, or tools an agent accesses.

Skill and plugin data

The distributed Goal to Proof package contains instructions, metadata, documentation, tests, and development utilities. It does not send prompts, task content, files, or usage telemetry to the maintainer. It does not create a Goal to Proof account or connect to a maintainer-operated server.

The skill runs within the AI agent host selected by the user. That host may process conversation content, files, tool calls, diagnostics, or usage data under its own terms. If an agent uses web search, source-control hosting, deployment services, or other tools while following the skill, those services also apply their own data practices and permissions.

Documentation website data

This website is static. It does not include a first-party analytics script, advertising tracker, contact form, account system, or Goal to Proof cookie. The site is hosted by GitHub Pages, so GitHub may process request data and operational logs under the GitHub General Privacy Statement.

Source-corpus privacy

The initial behavior design was informed by aggregate analysis of prior real working sessions. Raw conversations were not published. Session transcripts, secrets, private content, personal names, one-off preferences, and private corpus metadata were excluded from the public package. The repository contains generalized work principles rather than a copy of personal history.

Information you choose to submit

If you open a GitHub issue, discussion, or pull request, the content and account information you submit are handled by GitHub and may be public. Do not include secrets, private prompts, personal data, credentials, or confidential project material. Security vulnerabilities should use the private process described in the repository's security policy.

Children's privacy

Goal to Proof is a developer-oriented open-source project and is not directed to children. The project does not knowingly collect personal information from children.

Changes

Material changes to this notice will be committed to the public repository. The effective date above will be updated when the policy changes.

Contact

For privacy questions, use the public contact options on the Goal to Proof GitHub repository. Do not post sensitive information in a public issue.
