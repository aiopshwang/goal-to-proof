# Support

## Questions and usage help

Use [GitHub Discussions](https://github.com/aiopshwang/goal-to-proof/discussions) for setup questions, workflow examples, and ideas that are not yet concrete bug reports.

## Bugs and feature requests

Use [GitHub Issues](https://github.com/aiopshwang/goal-to-proof/issues) for reproducible defects and focused feature requests. Before opening an issue, search existing reports and include:

- the Goal to Proof version;
- the agent host and version;
- installation method;
- a minimal prompt or reproduction;
- expected and observed behavior;
- relevant logs with secrets removed.

## Security and sensitive reports

Follow [SECURITY.md](SECURITY.md). Never put secrets or undisclosed vulnerabilities in a public issue or discussion.

Support is community-maintained and provided on a best-effort basis; no response-time guarantee or service-level agreement is offered.
